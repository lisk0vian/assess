# Agents

Before designing or changing an interface, read the design system for that surface:

- Teacher terminal (`internal/tui`): [internal/tui/DESIGN.md](internal/tui/DESIGN.md), with its canvas in `internal/tui/design/canvas.html`
- Student web app (`web`): [web/DESIGN.md](web/DESIGN.md)
- Product truth for both: [PRODUCT.md](PRODUCT.md)

The terminal inherits the student app's world, so a colour or rule change starts in `web/DESIGN.md`.
